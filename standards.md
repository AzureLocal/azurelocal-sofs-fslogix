# Simple standards

## Scripts
Script and code standards for the Azure Local SOFS + FSLogix repository. This includes formatting, naming conventions, and best practices for each supported tool (PowerShell, Azure CLI, Bicep, ARM, Terraform, Ansible).

## Documentation
Documentation standards for the repository, including structure, formatting, and style guidelines for the architecture overview, getting started guide, and contributing guide. This ensures consistency and clarity across all written materials.

## Solutions
Standards for the actual deployment solutions provided in the repository, such as how to structure the Bicep templates, ARM JSON files, Terraform configurations, and Ansible playbooks. This includes best practices for modularity, parameterization, and maintainability.
